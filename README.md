Smart Plant Watering System Using Fuzzy Logic

Project Overview

This project is a Python-based Smart Plant Watering System that uses fuzzy logic concepts to determine watering duration based on soil moisture levels.

The system evaluates soil moisture and calculates a suitable watering time using fuzzy membership values.

Features

- Developed using Python.
- Uses fuzzy logic membership functions.
- Classifies soil moisture into Dry, Normal, and Wet conditions.
- Calculates watering duration based on moisture levels.
- Accepts soil moisture values from 0 to 100.
- Displays membership values and watering time.

How It Works

1. The user enters a soil moisture value between 0 and 100.
2. The program calculates Dry, Normal, and Wet membership values.
3. A weighted average is used to calculate the watering duration.
4. The system displays the results in minutes.

Example Output

Input: Soil Moisture = 50

Output:

- Dry Membership: 0.0
- Normal Membership: 1.0
- Wet Membership: 0.0
- Watering Time: 10.00 minutes
